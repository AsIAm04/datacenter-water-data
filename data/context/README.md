# Context data (not mapped)
rosa2026_us_water_gap_exposure.csv: US row of the supplementary dataset to Rosa, Sangiorgio, Scanlon, Mazzotti, Berry & Michalak (2026), Environ. Sci. Technol. 60, 27780-27791, https://doi.org/10.1021/acs.est.6c08088 (Zenodo 22912911, CC BY 4.0). The record holds country-level counts only (no data center coordinates), so it cannot be mapped by county. Counts are data centers in the authors' compilation by months per year of modeled water gap (demand exceeds supply in a global hydrological model; grid resolution not verified here), baseline 2001-2010 and a +3 C scenario (scenario values are fractional in the source). Exposure is not operational or community impact. The authors' US total (3,619) differs from this project's OSM atlas (2,018 rows).
